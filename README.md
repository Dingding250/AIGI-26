# AIGI-26
AIGI-26: A Benchmark for AI-Generated Image Detection Across Diverse Modern Generators


## Overview

### AIGI-26 Benchmark
AIGI-26 is a new benchmark for AI-generated image detection, comprising 253,200 real and generated images from 26 open-source and closed-source generators released between 2025 and 2026.

### MAFDNet
We further propose MAFDNet, which integrates multi-view spatial forensic statistics with radial–directional spectral features. With only 1.04M parameters, MAFDNet achieves 88.5% Acc and 94.9% AP on the test set, while demonstrating strong cross-dataset generalization capability.
